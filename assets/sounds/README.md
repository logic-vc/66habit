# Sound Assets

이 폴더에 사운드 파일을 추가하세요.

## 필요한 사운드 파일

1. **shutter.mp3** - 체크 완료 시 카메라 셔터 소리
2. **tick.mp3** - 게이지 채우는 동안 틱틱 소리 (선택사항)
3. **success.mp3** - 성공 딩동 소리
4. **milestone.mp3** - 마일스톤 달성 시 박수/환호 소리

## 사운드 파일 요구사항

- **포맷**: MP3 (권장) 또는 WAV
- **크기**: 각 파일 10-30KB 이하 권장
- **길이**: 0.5-2초 정도의 짧은 사운드
- **품질**: 낮은 레이턴시를 위해 압축된 파일 사용

## 무료 사운드 리소스

- [Freesound.org](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

## 참고

현재는 사운드 파일이 없어도 앱이 정상 작동합니다.
사운드 서비스는 파일이 없으면 자동으로 무시합니다.
